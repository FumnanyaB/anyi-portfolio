# anyi-portfolio
Anyi — Discover Communities. Build Connections.

A community discovery and engagement platform designed to help people find meaningful connections through shared interests, activities, and goals.

Role: Founder & Full-Stack Developer
Status: Active Development
Tech Stack: Next.js, React, TypeScript, Tailwind CSS, Supabase, Google Places API, Vercel

Overview

Anyi (meaning "we" or "us" in Igbo) is a community-focused platform built to make discovering and joining local communities easier.

The project addresses a common challenge: finding people and groups who share similar interests, especially when moving to a new city or looking to build meaningful relationships.

Anyi brings community discovery, group activities, and event information into one accessible platform.

Key Features

Community Discovery

Search for communities based on interests and activities.

Explore fitness, sports, technology, business, culture, and wellness groups.

Discover external communities through Google Places integration.

Community Management

Create and manage community circles.

View community details, members, and events.

Upload community logos and organize group information.

Social Discovery

Discover communities through Instagram and TikTok-related search features.

Browse community listings with responsive layouts.

User Experience

Responsive interfaces for desktop and mobile.

Reusable React components.

Intuitive navigation and community browsing.

Technical Implementation

Frontend: Next.js, React, TypeScript, Tailwind CSS

Backend: Next.js API routes and server-side functionality

Database: Supabase

External APIs: Google Places API

Deployment: Vercel

Version Control: Git and GitHub

My Contributions

As the founder and developer, I am responsible for translating the product concept into a working application.

My work includes designing user interfaces, developing frontend components, implementing backend API routes, integrating external services, and troubleshooting application functionality.

I also make product decisions based on usability, community needs, and opportunities to improve the discovery experience.

Engineering Challenges

External Community Discovery

Developing search functionality that helps users find relevant communities across different sources while handling inconsistent or incomplete listing information.

Responsive UI Design

Designing layouts that adapt to the availability of community images, logos, and other content.

Full-Stack Integration

Connecting frontend interactions with backend services, database functionality, and external APIs.
